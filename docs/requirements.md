# pj-mikke 要件定義書 v0.1

作成日: 2026-11-01

## 1. 目的

おもちゃで埋め尽くされた「子ども部屋」を 3D で作り、その中を自由に動き回りながら、
隠れたおもちゃを探して遊べるアプリを作る。

- 絵本のような「決まった構図で見るページ」と「自由に歩き回る探索」を、1 つの世界の中で両方できるようにする。
- 最初のゴールは **Room（子ども部屋）1 部屋** を作ること。
- 参考資料: `prototype/Room.pdf`（市販の絵本をスキャンしたもの。2 ページで 1 見開き、全 3 見開き）。
  密度・質感・「部屋全体 → 床 → 小さな入口」と視点が近づく流れは同じ水準を目指すが、
  写真の構図や物の並びをそのまま写すことはしない（著作権のため）。配置とデザインはオリジナル。

## 2. 技術選定（決定）

| 項目 | 採用 | 理由 |
|---|---|---|
| 実行環境 | Web ブラウザ（PC） | インストール不要、すぐ共有できる、Claude がブラウザで動作確認できる |
| 3D ライブラリ | three.js r170（`prototype/vendor/` に同梱） | 軽くて実績がある。ビルドツールなしで動く |
| モデル制作 | **コードで形を組み立てる（プロシージャル生成）** | Blender のような手作業の GUI が不要。100 個以上のおもちゃを色・大きさ違いで量産しやすい |
| ビルド | なし（ES Modules を直接読み込み） | npm などの準備が不要。`python -m http.server` だけで動く |
| 将来の拡張 | 写実的なモデルが必要になったら Blender で作った glTF を読み込めるようにする | 最初は不要 |

Blender / Unity は使わない。理由: 今回の世界は「単純な形のおもちゃを大量に並べる」ことが中心で、
コードで生成する方が速く、修正も Claude だけで完結できるため。

## 3. 世界のルール（縮尺）

- 単位: **1 = 1 メートル**（現実の部屋と同じ寸法で作る）。
- 部屋: 幅 4.0m × 奥行 3.6m × 高さ 2.5m。
- プレイヤーは **身長 8cm の小さなおもちゃの人形** という設定。目の高さ 7cm。
  → 普通の積み木が自分の背丈ほどあり、ベッドは崖、机は高台に見える。これが「おもちゃの世界」の体験の中心。
- 家具は実寸、おもちゃも実物と同じくらいの大きさ（積み木 4cm、トラック 30cm、ぬいぐるみ 30〜40cm など）。

## 4. 機能要件

### MVP（今回作るもの）
| ID | 機能 | 内容 |
|---|---|---|
| F1 | 部屋 | 床（木目）、壁（水色の水玉模様）、天井、窓とカーテン、ドア、幅木 |
| F2 | 家具 | ベッド、ナイトテーブル（引き出し＋棚）、スタンドライト、おもちゃ箱、木の椅子、本棚 |
| F3 | おもちゃ | 20 種類以上を組み合わせて合計 100 個以上を配置（ぬいぐるみ、ロボット、トラック、積み木、文字タイル、ボール、ビー玉、コマ、本、木のレール、地球儀 など） |
| F4 | 配置 | 乱数の種を固定した自動配置。毎回同じ並びになる。家具の上・中・床に散らばる |
| F5 | 移動モード | **歩く**（人形サイズ、重力あり・段差をよじ登れる）／**飛ぶ**（自由に飛び回る）。Tab キーで切り替え |
| F6 | 見開き視点 | 1〜3 キーで絵本の見開き（2:1 の横長、中央に綴じ目）の構図にカメラが移動する。見開き1「部屋全体」→ 2「床の高さ」→ 3「壁の穴」と、だんだん小さな世界へ近づく |
| F9 | 壁の穴 | 椅子の後ろの壁の下にアーチ形の穴。手前は積み木の町、穴の向こうに次の世界（小さな町）が見える。将来ここから次の部屋へ移動する |
| F10 | 密度と質感 | おもちゃ 400 個以上。プラスチック・ブリキ・ニス塗りの木など、反射のある鮮やかな質感。ベッドはしわのあるシーツと毛布 |
| F7 | さがしもの | 画面に「さがすもの」リスト（5 個）。照準を合わせてクリックすると見つけたことになる |
| F8 | 画面表示 | 操作説明、現在のモード、見つけた数 |

### 将来（今回は作らない）
- 部屋の外の世界（森、空、街）と、部屋から外へ視点が移っていくストーリー（全 10 ページ程度）
- 窓の外やドアの先に次の世界をつなげる
- スマホ操作、保存、効果音

## 5. 非機能要件

- 普通のノート PC のブラウザ（Chrome / Edge）で 60fps 前後。
- 同じ形のおもちゃは使い回し（ジオメトリ・マテリアル共有）で軽くする。
- 外部通信なし（three.js は同梱）。

## 6. 操作

| キー | 動作 |
|---|---|
| クリック | 画面をつかむ（マウスで視点操作）／さがしものを選ぶ |
| W A S D | 移動 |
| Space | ジャンプ（歩く）／上昇（飛ぶ） |
| Shift | 下降（飛ぶ） |
| Tab | 歩く ⇔ 飛ぶ |
| 1〜5 | ページ視点へ移動 |
| Esc | マウスを放す |

## 7. ファイル構成

```
pj-mikke/
  docs/requirements.md        この文書
  .claude/agents/             モデル別の担当エージェント定義
  prototype/
    index.html
    vendor/three.module.js
    src/
      main.js        起動・描画ループ（Opus）
      scale.js       寸法・縮尺の定数（Opus）
      textures.js    木目・水玉などの模様（Sonnet）
      room.js        部屋と家具（Sonnet）
      toys.js        おもちゃの形を作る関数（Sonnet）
      scatter.js     おもちゃの自動配置（Sonnet）
      controls.js    歩く・飛ぶ・ページ視点（Sonnet）
      hunt.js        さがしもの（Sonnet）
```

## 8. モデルの使い分け（このプロジェクトでの運用）

| 作業 | モデル / エフォート |
|---|---|
| 要件定義・世界のルール・ファイル分担の設計・最終確認 | Opus 5.5 / high（メイン） |
| 部屋・家具・おもちゃ・操作の実装 | Sonnet 5.5 / medium（サブエージェント） |
| 説明書・名前の整理など簡単な作業 | Haiku 5.5 / low（サブエージェント） |
| 原因不明の不具合・大きな設計変更 | Opus 5.5 / high〜xhigh |
| Fable 5.1 | 使わない（Pro の定額外になる可能性があるため） |

**費用のルール:** Claude Pro のサブスクリプション以外の料金がかかるものは使わない
（Fable、有料 API・API キー、有料のクラウドやホスティング、有料素材・ツール）。必要そうな場合は必ず事前に相談する。

## 9. 完了条件（MVP）

1. `prototype` でサーバーを起動し、ブラウザで部屋が表示される。
2. 歩く／飛ぶ／ページ視点の切り替えができる。
3. おもちゃが 100 個以上置かれている。
4. さがしもの 5 個をすべて見つけるとクリア表示が出る。
5. ブラウザのコンソールにエラーが出ない。
